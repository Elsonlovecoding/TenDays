## 填写方法

每找到一条证据，复制下面这个块填一份：

```
- 引用：「粘贴原文」
  章节:
  含义: （这句话对建模 / 灯光 / 声音 / 交互意味着什么）
  确定度: 明确 / 暗示 / 推断
  优先级: 高 / 中 / 低
```

**确定度三档：**
- **明确** = 原文直接写出
- **暗示** = 原文没直说，但能合理推出
- **推断** = 你自己的脑补（原著党看了不会反对，但书里确实没写）
